About OpenAppleModels

OpenAppleModels is an open-source framework and developer runtime engineered by SpaceCorps that unlocks real, deterministic tool calling and agent loops for Apple's on-device Foundation Models. It enables game developers, mobile engineers, and autonomous AI agents to build zero-latency, private AI experiences on iPhone, iPad, Mac, and Apple Vision Pro without API keys or cloud server costs.

Why We Built It: The Probing Evidence

macOS 27 introduced Apple's native fm CLI tool and an OpenAI-compatible fm serve local endpoint. However, rigorous probing revealed that fm serve injects your tools but never emits tool_calls (0 of 54 attempts in systematic testing), and setting tool_choice: "required" returns an HTTP 500 error. Within the native Swift FoundationModels framework, setting toolCallingMode: .required causes the model to call tools in an infinite loop without ever generating an answer.

SpaceCorps engineered OpenAppleModels to solve these fundamental limitations at the engine level.

Core Innovations

OpenAppleModels introduces fine-grained per-step loop control: requiring a tool call on step 1 to ground the response (e.g. checking game inventory or player health), then automatically transitioning to generating natural dialogue or structured JSON. It provides dynamic JSON Schema tool conversion, game NPC personas with episodic memory, an embeddable OpenAI-compatible HTTP server with genuine tool_calls streaming, and a high-performance JSON-RPC 2.0 bridge over stdio and C ABI for Unity, Godot, and Unreal Engine.

SpaceCorps Standards

Like every SpaceCorps project, OpenAppleModels is built for zero runtime bloat, uncompromising privacy (100% on-device processing), deterministic testing via scripted models, and universal developer accessibility under the MIT license.

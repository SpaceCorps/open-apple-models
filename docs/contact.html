Contact & Support

OpenAppleModels is maintained as an active open-source project by SpaceCorps. We welcome bug reports, game engine integration stories, performance benchmarks, and feature contributions.

Support & Community Channels

  • GitHub Issues: For reporting unexpected model behavior, schema conversion issues, and tool loop crashes, visit github.com/SpaceCorps/open-apple-models/issues.
  • GitHub Discussions: For game AI architecture, NPC persona design, Unity/Godot C ABI bindings, and agent loop patterns, join github.com/SpaceCorps/open-apple-models/discussions.
  • SpaceCorps Organization: Discover more native developer tools and autonomous agent infrastructure at github.com/SpaceCorps and spacecorps.github.io.
  • Email: Reach the core maintainers directly at contact@spacecorps.dev.

Security & Responsible Disclosure

To report potential security vulnerabilities or guardrail bypass bugs in structured output enforcement, please submit a report through GitHub Private Vulnerability Reporting on the repository.

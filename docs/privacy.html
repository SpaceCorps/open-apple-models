Privacy Policy & On-Device Security

Last updated: September 24, 2026. OpenAppleModels was built from the ground up on a fundamental commitment: all intelligence remains strictly on the user's device.

1. Zero Telemetry & 100% On-Device Processing

OpenAppleModels contains zero tracking code, zero analytics SDKs, and zero telemetry beacons. Neither prompts, tool parameters, world-state data, game dialogue, nor model completions are ever transmitted to SpaceCorps or any third-party cloud service.

2. Apple Intelligence Architecture

The framework interfaces directly with Apple's native on-device FoundationModels system service, executing inferences locally on the device's Apple Silicon Neural Engine (NPU). There are no cloud inference endpoints, no remote LLM servers, and no external token meters.

3. Zero API Key Requirements

Because computation runs locally on the device hardware, OpenAppleModels requires no API keys, developer tokens, credit cards, or account credentials. You never have to worry about credential leakage or billing surprise.

4. Documentation Website Privacy

This static documentation website is hosted on GitHub Pages. It uses no tracking cookies, analytics scripts, or user profiling. Access logs are maintained by GitHub according to GitHub's standard Privacy Policy.
